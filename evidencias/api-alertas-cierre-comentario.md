# Trabajo pendiente después del issue #61

Publicado como [comentario de seguimiento del issue #61](https://github.com/Jaimewww/sistema-practicas-preprofesionales-unl/issues/61#issuecomment-6392456159) y descrito en la sección de trabajo pendiente del [PR #72](https://github.com/Jaimewww/sistema-practicas-preprofesionales-unl/pull/72). La persistencia compartida queda fuera de este aporte.

---

Este aporte completa las alertas y el cierre del prototipo con estado coherente dentro del mismo navegador. Queda para otro issue implementar persistencia compartida entre usuarios y navegadores para el flujo estudiante → tutor → coordinador, con identidad autenticada, permisos por carrera y almacenamiento de reportes, validaciones y decisiones. Actualmente, un reporte enviado en un navegador no aparece automáticamente para un tutor que utiliza otro navegador. Esa ampliación requiere diseño y pruebas de integración propios.
